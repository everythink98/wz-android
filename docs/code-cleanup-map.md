# 技术债务与待验收项

## 使用边界

本文只索引已确认待处理的问题与验收缺口；事故状态、根因和关闭条件统一维护在[回归语料库](regression-corpus.md)，测试方法和设备操作分别见[测试标准](testing-standard.md)与[维护手册](operator-runbook.md)。代码修复、自动测试通过和设备验收完成分别判断；本清单不授予产品修复或设备变更权限。

## 待处理入口

| 问题或缺口 | 历史入口 | 下一份有效证据 |
| --- | --- | --- |
| 重图自动原图生命周期与整体容量 | `REG-TOPIC-144`、`REG-PERF-025` | 匹配源码 Release 的同条件重图流程；代码修复与局部成功不关闭完整设备门槛，App 故障与模拟器故障分别取证。 |
| 正文连续选择 | `REG-TOPIC-100`、`REG-TOPIC-146` | 独立 AVD instrumentation，以及匹配 APK 的主楼复制、跨回收窗口、返回与逐帧几何；物理设备触感单列。 |
| 续读与超高回复定位 | `REG-TOPIC-148/149` | 四站无按钮双向续读、重复定位和关联交互；尾窗底部收缩须核对 content layout 夹紧与 Native MVCP 的真实顺序。 |
| 嵌套 Tab 内宽与表情失败恢复 | `REG-TOPIC-147`、`REG-WRITE-077` | 匹配 APK 的真实入口、自然图片失败、恢复后位置和返回；既有自动 owner 不能代替这些分支。 |
| NodeSeek 终端 Tab 内容与性能 | `REG-TOPIC-150` | 全文复制读回；JS 派生、Native 文档更新和文本布局分别测量，复制提示或桌面规模探针不替代设备证据。 |
| Search 转场连续 deadline miss | `REG-PERF-024` | 维护手册的三批 Release 往返测量，同时检查帧耗时和连续 miss，不能只凭 p95/worst 关闭。 |
| 慢网切来源时图片崩溃 | `REG-FEED-026` | 建立最小重复 oracle 和同条件对照，再判断图片生命周期根因；刷新进行中切来源/底栏的缺口仍保留。 |
| 更新下载偶发字节丢失 | `REG-UPDATE-008` | 按原条目等待后续复现日志，不猜测改动、不放宽 SHA 校验。生产 More 的正式新版下载到最终安装仍按 `LOCAL-UPDATE-01` 独立验收。 |

已标为 `RESOLVED` 的事故也可能保留部分未验证分支，例如首页手势的物理设备触感、实际列表尾部斜滑及刷新交叉操作；具体范围读对应条目的验证边界。本表不复制全部已修复事故或测试清单。

## 后续处理

- 新问题先记录可复现证据与授权状态；完成条目要求的验证后更新 corpus，并从本表移除已经闭合的入口。
- NodeSeek 投票区间替换与深度有界选区编译器保留规模基准；未证明热点或嵌套区间错误前不进入重写范围。文件大小、目录观感和推测性扩展点不构成债务。
- 代码组织和内部模块迁移遵循[代码规范](code-standards.md)。生成目录与本机产物的清理遵循[交接说明](handoff.md#文档与记忆收口)，不算作产品债务完成。
