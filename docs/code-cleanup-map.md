## 后续处理

- 取得新证据后，更新回归语料库的当前结论与验收边界，并同步移动或移除本索引入口。只有达到条目关闭条件后才能更新事故状态；不删除历史 ID，也不重复计算相关事故。
- NodeSeek 投票区间替换与深度有界选区编译器保留规模基准；未证明热点或嵌套区间错误前不进入重写范围。文件大小、目录观感和推测性扩展点不构成债务。
- 代码组织和内部模块迁移遵循[代码规范](code-standards.md)。生成目录与本机产物的清理遵循[交接说明](handoff.md#文档与记忆收口)，不算作产品债务完成。
