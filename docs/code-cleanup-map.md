# 用户旅程技术债务清单

## 当前状态

当前确认的未闭合项为 `REG-TOPIC-144`：自动原图共享 gate 与注册生命周期的代码/自动化证明不能替代匹配源码的 Release 重图设备验收，取得该证据前保持 `OPEN`。Android 连续选择的独立 AVD instrumentation 和物理设备触感证据也不得由主登录态 AVD 或普通 UI 测试替代，按测试标准分别报告证据缺口。NodeSeek 投票区间替换及深度有界选区编译器只记录规模基准，未证明热点或嵌套区间错误前不进入重写范围。新发现先记录可复现证据与授权状态；文件大小、目录观感或推测性扩展点不构成债务。

## 清理约束

- 四项修复的自动化 owner 覆盖 V2EX 明确引用、作者/身份冲突、持续锚定、选择返回、表情失败恢复和内宽传播；新版 APK 的真实入口、双向续读及系统返回另行验收。共享续读的 key/几何基线、原生确认、首次布局门禁及暖态超高回复定位已有行为 owner，历史分别见 `REG-TOPIC-148/149`；最终候选的四站无按钮续读、重复定位及关联交互完成前不关闭设备证据缺口。Android 尾窗底部内容收缩还须核实 content layout 先夹紧、MVCP 后补偿的真实结果，不用零 offset 收缩或单次 clamp 的模型代替，也不据此直接新增 JS 补滚。自然图片失败、物理设备边缘返回或完整 Release 性能没有实际证据时保持未验证，不以单测或旧 APK 观察关闭。不能用只含回复的几何用例或同步原生回调假设替代设备证据。
- 本轮备份、journal、代理、媒体准入及 Unicode 编辑器边界已有行为 owner；测试替换与历史见产品地图及回归语料。NS 页签优化先以工作量/提交次数验收，匹配源码设备上的 JS 派生、Native 文档更新和文本布局耗时分别待测，不能以桌面规模探针代替。
- NS 抓取空/部分终端骨架的完整源码恢复已有共享入口及歧义反例，见 `REG-TOPIC-150`；C17 匹配 APK 已取证四 Tab 全文、横滑/位置保持、选择返回、预览翻页与两轮图片恢复，剪贴板全文读回仍受 Android 工具限制，不能以复制提示关闭该缺口。优化等价复核中发现的 Search 首屏权限/重复项与缓存截页偏差已纠正，仍保留单次线性合并和空缓存复用，不把行为变化当作性能收益。
- 代码组织和内部模块迁移约束见 `docs/code-standards.md`。
- `android/` 是生成目录，不把生成结果当长期配置，也不把删除生成目录算作产品债务完成。
- 每项债务完成时，在对应测试和真实旅程验收通过后从本清单删除；未完成部分应缩小描述，不能改名后继续悬空。
