# 模拟器功能基线

## 2026-06-22 基线

| 项 | 内容 |
| --- | --- |
| 设备 | `emulator-5554` |
| App | `com.wz.reader` |
| 版本 | `1.3.13` |
| 启动方式 | Expo development build + Metro `8081` |
| 数据处理 | 未卸载、未清数据、未清 Cookie、未重置模拟器 |
| 范围 | 只读验收；不执行发帖、回复、点赞、收藏切换、取消关注、删除、清空、导入、导出、退出登录、清除登录、保存图片、安装更新 |

这份记录描述“当前代码在当前登录态下是什么样”。以后优化代码时，新结果不要求和实时网站数字永久一致，但同一天、同条件、同登录态下不能无故少结果、丢字段、打不开详情或丢返回状态。

后续说“全面测试”时，默认仍按只读边界执行；不主动真实发帖、回复、编辑、删除、点赞、投票或切换收藏。确实需要真实写操作验收时，必须先得到用户明确同意，临时内容必须中文且贴合主题，并在完成后删除。

当前 `codex` 的 NodeSeek 结果来自已登录状态下的站内搜索；未登录时 NodeSeek 可能跳到 Google 搜索页，该路径作为兼容标准和自动化测试覆盖，不等同于本次模拟器结果。

| NodeSeek 自己回复操作区 | 自己的回复不显示赞 / 鸡腿 / 反对；只有同时有评论 id 和原始正文时显示 `编辑`；操作区间距不能因为隐藏按钮变散 |

| NodeSeek 回复 token | 已登录后从 App 内登录页或详情页取得真实 token；真实回复 / 编辑缺 token 时必须提示重新检测登录，不允许用随机 token 发送 |
| NodeSeek NodeImage | 无 Key 时点图片自动打开 App 内 NodeImage 授权；授权成功后缓存 Key；force-stop 后再次上传不重复授权；401 / 403 后只刷新一次 Key |
| 三站图片上传 | NodeSeek、linux.do、妖火上传成功后只插入草稿，不自动发送；NodeSeek / linux.do 为 Markdown 图片，妖火为 `[img]...[/img]` |
| 三站回复失败恢复 | 人为遇到或制造发送失败后，同一个输入框仍可点击、可改文字、可再次发送；不允许靠收起再展开恢复 |
| 回复删除 | 默认不新发临时回复、不真实删除；只检查删除入口、权限显示和确认框取消，删除成功后的列表变化由自动测试覆盖 |
| 日志 | 验收后检查 `ReactNativeJS`、`AndroidRuntime`，不得有红屏、未处理异常或崩溃 |
